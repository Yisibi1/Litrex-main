Güvenli & Bağımsız

OLibrary herhangi bir içerik barındırmaz. Sadece herkese açık köprüleri (manifest) indeksler. Telif haklarına saygılı, yasal ve bağımsızdır.

Açık Spesifikasyon

Manifest ve eklenti standardımız tamamen açık kaynaklıdır. Geliştiriciler kendi API köprülerini veya halka açık kaynaklarını kolayca uyumlu okuyuculara bağlayabilir.

Süper Hızlı Entegrasyon

Kullanıcılar tek bir tıkla veya manifest linkini kopyalayarak saniyeler içinde yeni veri köprülerini medya oynatıcılarına ekleyebilirler.

Geliştirici Protokolü

Kendi API köprünüzü uyumlu medya okuyucularına bağlamak için aşağıdaki olib:// URI şemasını kullanın.

Eklenti Ekleme — Deep Link Formatı

olib://addon?url=https://siteniniz.com/addon.json

Bu URI şeması, olib:// protokolunu destekleyen medya okuyucularında tek tıkla eklenti yüklemeye olanak tanır. Kullanıcı bağlantıya tıkladığında uygulama açılır ve manifest bağlantısını onaylamasını ister.

✦  Manifest dosyanız (addon.json) standart OLibrary şemasına uygun olmalıdır. Demo için bu dosyayı inceleyebilirsiniz.
